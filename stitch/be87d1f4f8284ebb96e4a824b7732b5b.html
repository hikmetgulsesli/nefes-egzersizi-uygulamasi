# Nefes Egzersizi Uygulaması — PRD ## 1. Project Overview **Project Name:** Nefes Egzersizi (Breath Flow) **Type:** Single-page Web Application (SPA) **Core Functionality:** An animated breathing exercise app with guided breathing techniques (4-7-8, box breathing, simple breathing), session history, and statistics tracking. ## 7. UI/UX Requirements ### 7.1 Visual Design — Dark Theme (Default) **Color Palette:** - Background: `#0D1117` (deep dark) - Surface: `#161B22` (card backgrounds) - Surface Elevated: `#21262D` (modals, dropdowns) - Primary: `#58A6FF` (interactive elements, breathing circle glow) - Primary Muted: `#1F6FEB` (secondary actions) - Accent Calm: `#7EE787` (success, calm mood) - Accent Warm: `#FFA657` (warnings, exhale phase) - Text Primary: `#E6EDF3` - Text Secondary: `#8B949E` - Text Muted: `#484F58` - Border: `#30363D` **Typography:** - Font Family: `'Inter', system-ui, -apple-system, sans-serif` - Heading XL: 32px / 700 weight - Heading L: 24px / 600 weight - Timer Display: 64px / 300 weight (monospace for numbers)
